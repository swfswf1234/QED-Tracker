## 背景

根仓库 ADR 0006 将治理契约设计显式化为可移植范本（守护面清单七类、契约头六字段、编写约定
与新增流程），并声明子项目按其文档体系适配（`ROOT` 推导、DesignRef 指向自身标准、ADR 独立
编号、守护面按目录裁剪），对齐以跨项目请求推进。根仓库已登记 REQ-023（2026-08-09 用户确认
范本化设计）。

本仓库现有文档与结构测试（如 `tests/test_documentation.py`）具备守护职责，但未按范本声明
契约头六字段与守护面归属，新增守护只能参照既有文件。

## 变更内容

1. **契约头六字段**：现有守护类测试补齐模块职责、设计关联（DesignRef，指向本仓库标准）、
   实现状态、被测代码、守护面、失效后果六字段 docstring。
2. **守护面清单裁剪**：按本仓库文档体系（architecture/design/standards/guides/trackers）适配
   守护面七类清单，不强制覆盖根仓库全部守护面。
3. **新增流程采纳**：新增守护测试遵循范本编写约定（纯标准库、自包含、零网络）。
4. 对齐以本仓库门禁全绿为验收，不改变既有守护逻辑。

## 成功标准

- 本仓库守护类测试全部声明契约头六字段（DesignRef 指向本仓库标准文档）。
- 对齐后 `pytest` 全绿 + ruff 全过（本仓库门禁）。
- 回执根仓库 REQ-023（提交号 + 测试输出）。
