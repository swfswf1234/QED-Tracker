## 目标与成功标准

**目标**：对照根仓库 ARCH-024 三线范围（本地模型链路 / 论文探索和下载 / 下载链路评估与 bug 修复），
把本仓 v1.0 的全部后续任务梳理成一条可排期的链条：明确主要任务次序、依赖关系、跨项目接口与
待裁决项，并登记进 todo 与本计划。**本计划只梳理与登记，不实现。**

**成功标准**：

1. 三线 → 本仓任务/子任务的映射无缺口（ARCH-024 滚动壳每条线都能指回本仓台账行）。
2. 任务链条的批次顺序与依赖理由经用户评审确认，作为 v1.0 排期依据。
3. 待裁决项（调研稿 §7 遗留）集中列出，一次评审可全部裁决。

**v1.0 交付口径（用户裁决 2026-09-24）**：v1.0 = **三条主线全部交付 + ARCH-024 三线优化
收口**，以本计划为口径索引；分主线口径与风险见「三主线与 v1.0 交付口径」节。
