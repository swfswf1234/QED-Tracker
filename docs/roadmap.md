# 后续规划

状态：Current
最后更新：2026-07-30

本文件只记录能力方向，不记录任务状态、负责人或完成勾选。实际变更以 Git 分支、提交和测试结果为准。

## 来源可靠性

- 为外部来源页面变化建立独立的人工连通性检查，结果不进入默认离线 CI。
- 复核来源授权、下载能力和可用性元数据，优先评估新的开放教材来源。
- 保持单个来源故障隔离，避免外部页面变化影响其他来源和本地清单。

## 目录与批处理

- 按现有 JSON schema 增加独立教材目录，不修改下载核心。
- 根据真实使用反馈完善批量恢复、失败报告和重复下载处理。

## Axiom-Flow 交付

- 在不共享数据库或数据目录的前提下完善传输状态查询。
- 继续保持默认只上传、显式解析和费用操作不自动重试的边界。

## 论文发现

- 建立人工标注的论文候选评测集，持续评估不同目标档案和模型版本的推荐精度。
- 根据真实使用反馈评估引用数据、周期跟踪和选择反馈；未经独立设计不得进入资源事实或自动下载链路。
