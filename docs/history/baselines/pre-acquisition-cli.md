## 保留目的

本文件解释 QED-Tracker 为什么从通用资源跟踪项目收敛为本地 PDF 获取 CLI。它只保存范围和迁移锚点，不复制旧代码、命令或文档树。

## 旧系统范围

聚焦重构之前，仓库曾同时承担 Web API、SQL 数据库存储、GitHub/RSS 采集、官方文档镜像、教材下载、论文获取和课程规划。职责之间共享配置、模型、仓储和脚本，导致数据边界、运行入口和文档事实相互冲突。

## 取代决定

2026-07-29 的聚焦重构将运行时固定为可安装的本地 CLI，只保留：

- 教材、习题集和 arXiv 论文的搜索与下载；
- PDF 结构校验、SHA-256 身份、去重和本地 JSON 清单；
- 只读冻结目录及严格匹配下载；
- 通过 HTTP 向 Axiom-Flow 显式交付 PDF。

Web 服务、数据库、非 PDF 资源中心、GitHub/RSS 跟踪和官方文档镜像退出当前范围。Axiom-Flow 负责导入后的解析、审阅和知识发布。
